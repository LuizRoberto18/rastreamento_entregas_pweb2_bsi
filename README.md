# rastreamento_entregas_pweb2_bsi

API simples para rastreamento de entregas usando Node.js e Express.

## Instrucoes de execucao

### Pre-requisitos

- Node.js 18+ (recomendado)
- npm

### Passos

1. Instale as dependencias:

	```bash
	npm install
	```

2. Inicie o servidor:

	```bash
	node src/server.js
	```

3. Acesse no navegador:

	http://localhost:3000

4. Endpoint principal da API:

	http://localhost:3000/api/entregas
